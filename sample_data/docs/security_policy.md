# Helios Robotics Information Security Policy

Policy code SEC-IS-2026.

## Passwords and Authentication

Passwords must be at least 14 characters long and must not be reused across systems. Multi-factor authentication is mandatory for email, source control, cloud consoles and VPN access. Hardware security keys are required for all production administrators.

## Devices

Company laptops must use full-disk encryption and lock automatically after 5 minutes of inactivity. Personal devices may access email only through the managed mobile app.

## Data Classification

Data is classified as Public, Internal, Confidential or Restricted. Customer telemetry and robot firmware signing keys are Restricted. Restricted data must never be uploaded to unapproved third-party AI tools.

## Incident Reporting

Suspected security incidents must be reported to the security team within 1 hour of discovery through the #sec-incident channel or by emailing the security on-call rotation.
